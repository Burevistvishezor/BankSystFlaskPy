# Bank System Flask v5.0

Мини-банковская система на Python с Flask.

## Функции
- Создание аккаунтов
- Депозит / снятие
- Переводы между аккаунтами
- Лог транзакций
- Сохранение данных в JSON

## Установка
1. Клонировать репозиторий
2. Создать виртуальное окружение
3. Установить Flask
4. Запустить `python app.py`
5. Открыть браузер на http://127.0.0.1:5000/
