# B# Bank System Flask v5.0

Мини-банковская система на Python с Flask.  
Позволяет создавать аккаунты, управлять балансом, переводить деньги между пользователями и вести историю транзакций.  

![Bank Screenshot](screenshot.png)  <!-- сюда можно вставить скриншот интерфейса -->

---

## ⚙️ Функции

- Создание аккаунтов с балансом
- Депозит / снятие средств
- Переводы между аккаунтами
- Лог всех транзакций
- Сохранение данных в `JSON`
- Web-интерфейс через Flask (HTML + CSS)
